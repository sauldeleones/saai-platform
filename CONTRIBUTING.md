# Guía para colaboradores de SAAI

¡Gracias por tu interés en contribuir a SAAI! Este proyecto es parte de una tesis doctoral open source y toda contribución es bienvenida.

## Cómo contribuir

### Reportar errores

1. Verifica que el error no haya sido reportado ya en [Issues](../../issues)
2. Abre un nuevo issue describiendo:
   - Qué esperabas que pasara
   - Qué pasó en realidad
   - Pasos para reproducirlo
   - Tu sistema operativo y versiones de Python/Node

### Proponer mejoras

1. Abre un issue con la etiqueta `enhancement`
2. Describe el caso de uso educativo que resuelve
3. Espera retroalimentación antes de codificar

### Enviar código

1. Haz fork del repositorio
2. Crea una rama descriptiva: `git checkout -b feature/nombre-de-la-mejora`
3. Haz tus cambios siguiendo la guía de estilo
4. Agrega o actualiza pruebas si aplica
5. Abre un Pull Request describiendo los cambios

## Guía de estilo

- Python: sigue PEP 8, usa type hints
- Commits: mensajes en español o inglés, verbos en imperativo
- Documenta funciones nuevas con docstrings breves

## Áreas donde se necesita ayuda

- [ ] Frontend React completo
- [ ] Soporte para más formatos de archivo
- [ ] Internacionalización (inglés, portugués)

## Código de conducta

Este proyecto sigue el [Contributor Covenant](https://www.contributor-covenant.org/). Se espera un ambiente respetuoso e inclusivo.
